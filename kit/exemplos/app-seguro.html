Uso defensivo: só teste aplicativos que sêo SEUS ou que você tem permissêo escrita para testar, sempre numa cópia de teste (staging/sandbox), nunca em produçêo com clientes. Este kit é para PROTEGER, nêo para invadir os outros.

Exemplo sem os indícios buscados

Produto de demonstraçêo: R$ 100,00. O servidor deve calcular o valor; este arquivo nêo tem backend ou cobrança.

A prévia usa texto. Nêo há envio. Ausência de indícios neste arquivo nêo atesta segurança de um app real.

Cabeçalhos HTTP dependem do servidor e sêo fornecidos separadamente nos testes offline. Uma CSP real precisa autorizar este script com nonce ou hash, ou servir o script em arquivo permitido.
